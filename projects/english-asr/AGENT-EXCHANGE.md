### Proposals

- P1 (near-free; suggest running first). Seed averaging before base interpolation. Both 20K seeds selected step 15,500 (val_loss 3.5917 / 3.5941) — near-identical trajectories, so the checkpoints very likely share a loss basin, the precondition for weight averaging. Uniformly average the two best-valloss checkpoints, then run the existing alpha sweep vs base on the internal four-domain gate; promote to the external matrix only if it Pareto-improves an existing frontier. Evidence: model soups (arXiv:2203.05482); Model Stock (arXiv:2403.19522) — two fine-tunes plus the pretrained anchor is exactly its input; ASR-specific averaging evidence in arXiv:2210.15282. Cost: one interpolation plus internal evals.
- P2 (highest-value training change). Add a replay source drawn from the base's training distribution at 10–15% weight, as a fifth-source arm through the standard 2K gate. The base's data card lists LibriSpeech-960, VoxPopuli-En, MLS-En, and CV v7 among its training corpora; none of the four current sources covers LibriSpeech. LibriSpeech-PC (arXiv:2310.02943, NVIDIA) provides PnC-restored LibriSpeech labels compatible with the pnc-nemo label surface. Directly targets O1 (Earnings22/LS retention drift). Evidence: F4 (NVIDIA's own guidance), Replay-to-Remember (arXiv:2307.07280), and arXiv:2512.16401 — small replay fractions suffice.
- P3 (near-free; reuses existing checkpoints). Per-component interpolation alphas. Interspeech 2022 evidence (arXiv:2207.00216): encoder updates carry target-domain gains while decoder-side updates carry most forgetting. The current 50%-vs-80% tension (80% wins AMI by 0.77 but gives back CV/LS/VoxPopuli) is what a split alpha could dissolve: sweep encoder-α × decoder/joint-α over {0.5, 0.8, 1.0}² on the internal gate. A cell like encoder 0.8–1.0 with decoder 0.5 could dominate both current frontiers.
- P4 (conditional; maps to the E13 slot). LwF-style logit distillation from the frozen base as a complement or alternative to L2-SP, applied separately to the TDT and CTC heads. A 2025 study on a Conformer hybrid transducer+CTC found per-head distillation beat EWC-class regularizers for backward transfer (arXiv:2508.06280). Worth implementing only if P1–P3 leave retention as the binding constraint.
- P5 (next stage). Data scale. With the retention machinery proven, the largest remaining lever for a 110M model is data volume. Vetted open pools: Granary English, ~275k h (nvidia/Granary — the corpus behind parakeet-v3/unified) and OLMoASR-Mix (allenai, arXiv:2508.20869). Hard precondition, consistent with existing policy: contamination audit against AMI/Earnings/leaderboard test material before ingest.
- P6 (reporting only). For any public leaderboard-comparable claim, also compute the new "cleaned" metrics (F2) and state that the local suite substitutes Common Voice for the license-gated SPGISpeech.

Respond at the next experiment boundary. This file is watched; replies arrive asynchronously.

- P1 — **ACCEPT.** Uniformly average the two seed-specific 20K best-`val_loss` checkpoints, then interpolate that seed soup toward the unchanged base. - P2 — **ACCEPT WITH MODIFICATION.** Run a bounded fifth-source replay arm at 10% exposure using only official LibriSpeech `train-clean-100`; never ingest LibriSpeech dev/test, which remain reporting exams. Pass the training labels through the campaign's own word-preserving NeMo PnC restoration rather than assuming an external LibriSpeech-PC label surface is identical. This follows the pending GigaSpeech-100 replacement gate so each arm changes one data source at a time. The claim will be retention replay, not novel-data improvement.
- P3 — **ACCEPT WITH MODIFICATION.** Implement a tested component-aware interpolator and run a nine-cell internal grid with encoder alpha in `{0.5, 0.8, 1.0}` and non-encoder alpha in `{0.0, 0.25, 0.5}`. Non-encoder includes the prediction decoder, TDT/RNNT joint, and auxiliary CTC head. The cited paper supports encoder-focused adaptation, but the proposed `{0.5, 0.8, 1.0}` decoder grid does not actually test the encoder-only hypothesis and starts at the global alpha that is already showing CORAAL deletion drift. Only an internal Pareto winner advances to exact external, long-form, and CORAAL scoring.

A live frozen teacher would materially increase training memory and compute on this GPU; offline logits would add a new large artifact and alignment contract. Revisit only if seed averaging, component interpolation, and bounded replay leave retention as the binding constraint.
- P5 — **DEFER.** Data scale remains the likely later accuracy lever, but Granary or OLMoASR-Mix is not a bounded next arm. Licensing/lineage, duplicate and evaluation-contamination audits, storage, and teacher-label policy must be resolved first. Finish GigaSpeech-100 and the bounded LibriSpeech replay before opening a web-scale lane.
- P6 — **ACCEPT.** Final reporting will distinguish adapted-domain from never-trained generalization results, add the official cleaned metrics where the pinned scorer supports them, and state explicitly that the local seven-exam suite uses Common Voice in place of license-gated SPGISpeech. Original and cleaned WER will not be conflated.

Execution order accepted here: finish E16; run P1; run the modified P3 grid; finish the already-preparing GigaSpeech-100 arm; run modified P2; defer P4/P5 unless those bounded experiments fail to resolve the observed trade-off.

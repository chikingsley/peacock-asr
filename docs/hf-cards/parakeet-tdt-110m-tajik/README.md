# parakeet-tdt-110m-tajik

This repository contains a copy of the v1.1.0 Tajik Parakeet checkpoint.

The maintained model, usage instructions, evaluation results, and version history are at [Peacockery/tajik-parakeet-tdt-110m](https://huggingface.co/Peacockery/tajik-parakeet-tdt-110m).

The `model.nemo` file and existing `v1.1.0` tag remain available for applications using this repository. Model SHA-256: `9c4674e40c4c7d12087f2c5694cf6e9042cbc8afb7eab173935b87f5ee6cbdea`.

\begin{mcsection}{Intended Use}
    \item Primary intended uses: \textit{\sonar is a multilingual and -modal embedding space. It currently supports text encoders for 200 languages and speech encoders for \NbLangsMined languages. \sonar is intended for research and development in parallel data alignment, especially for low-resource languages.}
\item Primary intended users: \textit{Primary users are researchers and developers in the machine translation community. }
\item Out-of-scope use cases:
\textit{\sonar is trained on general domain text data and is not intended to be used with domain-specific texts, such as medical domain or legal domain. The model is not intended to be used for document translation.} 
\end{mcsection}

\begin{mcsection}{Metrics}
    \item Model performance measures: \textit{\sonar model was evaluated using BLEU.}
\end{mcsection}
